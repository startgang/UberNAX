## 📋 МЕТОДИКА ТЕСТИРОВАНИЯ
```bash
# Нагрузка
stress-ng --cpu N --timeout 5m

# Мониторинг температуры и частот
watch -n 1 'sensors; echo "---"; grep MHz /proc/cpuinfo'

# Диагностика троттлинга
sudo /opt/throttled/venv/bin/throttled --monitor

# Управление лимитами мощности
sudo ./setPL.sh PL1 PL2
```

### Что изменено
```ini
Заводская алюминиевая пластина 5-7 мм заменена на радиатор
с тепловыми трубками той же толщины. Термопаста тонким
слоем с обеих сторон
```

```ini
| 8    | 73 Вт     | 91 Вт           | +18 Вт   |

```

### Температурный режим после доработки
```ini
| Ядер | Package | Активные ядра  | Thermal LIM      |
|------|---------|----------------|------------------|
| 2    | 93°C    | 96°C (Core 8, 12) | не срабатывает |
| 6    | 96°C    | 91-97°C        | не срабатывает   |
| 16   | 96°C    | 94-96°C        | не срабатывает   |
```

### Анализ
```ini
Прирост мощности +10…+21 Вт на всех режимах.
Thermal LIM перестал срабатывать — процессор не упирается
в температурный порог.

Разница температур между ядрами (60°C vs 96°C) вызвана
не градиентом кристалла, а тем, какие ядра были нагружены
планировщиком. Простаивающие ядра холодные, активные — горячие.
```

## 🔬 ПОТЕНЦИАЛ ДАЛЬНЕЙШЕГО УЛУЧШЕНИЯ

### Расчёт теплового сопротивления интерфейсов (при 80 Вт)
```ini
| Вариант                                  | R, К/Вт | ΔT, °C |
|------------------------------------------|---------|--------|
| Алюминий 5 мм + термопаста               | 0.0619  | 5.0    |
| Испарительная камера + прокладки (1 мм)  | 0.0972  | 7.8    |
| Испарительная камера + термопаста        | 0.0374  | 3.0    |
```

### Возможные улучшения
```ini
| Улучшение                          | Ожидаемый эффект       |
|------------------------------------|------------------------|
| Испарительная камера + термопаста  | -2…-3°C по интерфейсу  |
| Жидкий металл                      | -3…-5°C                |
| Зачистка порошковой краски         | -2…-5°C                |
| Суммарно                           | -8…-15°C               |
```

### Практический потолок
```ini
~115-120 Вт реальной мощности при TCC Offset = 10-15.
Дальнейшее уменьшение смещения приводит к превышению заявленного максимальнгго показателя TDP в режиме Turbo Boost.
```
